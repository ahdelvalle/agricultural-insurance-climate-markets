# Data Sources - Complete Reference List

This file provides direct URLs and access information for all data sources used in this study.

## Agricultural Price Data

### Canada - Ontario

**1. International Prices (FRED)**
- Source: Federal Reserve Bank of St. Louis
- Dataset: Global Price of Corn
- URL: https://fred.stlouisfed.org/series/PMAIZMTUSDM
- Format: Monthly, USD per metric ton
- Access: Public, free download
- Coverage: 1990-present

**2. Exchange Rates**
- Source: Bank of Canada
- Dataset: USD/CAD Exchange Rate
- URL: https://www.bankofcanada.ca/valet/observations/FXUSDCAD
- API: https://www.bankofcanada.ca/valet/docs
- Format: Daily, can aggregate to monthly
- Access: Public, free API access

**3. Farm-Gate Prices**
- Source: Grain Farmers of Ontario
- URL: https://gfo.ca/marketing/
- Backup: Ontario Ministry of Agriculture, Food and Rural Affairs (OMAFRA)
- URL: https://data.ontario.ca
- Format: Monthly reports
- Access: Public

### Mexico

**4. SNIIM (Sistema Nacional de Información e Integración de Mercados)**
- Agency: Secretaría de Economía
- URL: http://www.economia-sniim.gob.mx/
- Coverage: Jalisco, Sinaloa (and other states)
- Format: Web portal, requires manual extraction or web scraping
- Access: Free registration required
- Data availability: 1990s-present (varies by market)

### Brazil

**5. LAMFO Data**
- Institution: Laboratório de Aprendizado de Máquina em Finanças e Organizações
- University: Universidade de Brasília (UnB)
- Contact: Prof. Herbert Kimura
- Email: hkimura@unb.br
- URL: http://www.lamfo.unb.br/
- Coverage: Goiás, Mato Grosso
- Access: Available upon reasonable request, subject to institutional data sharing agreements
- Format: Processed CSV files

## Climate Data

### Canada

**6. Environment and Climate Change Canada**
- Agency: Environment and Climate Change Canada
- Portal: Historical Climate Data
- URL: https://climate.weather.gc.ca/
- Station Search: https://climate.weather.gc.ca/historical_data/search_historic_data_e.html
- Primary Station: Ottawa Macdonald-Cartier Airport
  - Station ID: 4333
  - WMO ID: 71628
  - Coordinates: 45.32°N, 75.67°W
- Format: CSV download
- Access: Public, Open Government License
- Coverage: 1889-present (varies by station and variable)

**7. GHCN-Daily (Alternative Source)**
- Agency: NOAA National Centers for Environmental Information
- URL: https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily
- Station: CA006106000 (Ottawa Airport)
- Access: Public, free download
- Format: CSV or API

### Mexico

**8. CONAGUA (Comisión Nacional del Agua)**
- Agency: Comisión Nacional del Agua
- Parent: SEMARNAT (Secretaría de Medio Ambiente y Recursos Naturales)
- Portal: Sistema de Información Climatológica Integral (SICI)
- URL: https://smn.conagua.gob.mx/es/climatologia/informacion-climatologica
- Access: Public registration required
- Coverage: ~5,000 stations nationwide
- Format: Web portal, Excel exports
- Study used: 415 stations in corn-growing regions

**9. CLICOM (Alternative Mexico Source)**
- System: CLICOM (CLImate COMputing)
- Operated by: Mexican National Weather Service
- Access: Through CONAGUA portal
- Format: Database exports

### Brazil

**10. INMET (Instituto Nacional de Meteorologia)**
- Agency: Instituto Nacional de Meteorologia
- Parent: Ministério da Agricultura, Pecuária e Abastecimento
- Portal: Banco de Dados Meteorológicos (BDMEP)
- URL: https://bdmep.inmet.gov.br/
- Alternative: https://portal.inmet.gov.br/
- Coverage: 
  - Goiás: 39 stations
  - Mato Grosso: 33 stations
- Access: Public with registration
- Format: CSV download
- Study period: 2002-2024

## Data Processing Tools

The following open-source tools were used for data collection and processing:

1. **R packages**:
   - `tidyverse` for data manipulation
   - `lubridate` for date handling
   - `SPEI` for SPI calculation
   - `httr` and `rvest` for web scraping

2. **Python packages**:
   - `pandas` for data manipulation
   - `requests` and `beautifulsoup4` for web scraping
   - `scipy` for statistical calculations

3. **APIs**:
   - Bank of Canada Valet API (https://www.bankofcanada.ca/valet/docs)
   - FRED API (requires free API key)
